# SAMPLE FILES - NOT THE MODEL INPUTS

Each `SAMPLE_*.csv` holds only the **first 5 rows and the last 20 rows** of the matching file in `data/raw/`.
The rows in between are left out on purpose, so the dates jump (for example from January 2000 to the latest month).

Why: S&P 500 and Yahoo Finance data may not be redistributed freely, so the public repository shows the
format only. These samples **cannot reproduce the results**.

The full frozen snapshot is in `data/raw/` inside the submitted evidence ZIP. `data/raw/SHA256SUMS.txt`
lets anyone confirm that those files are the ones used.
